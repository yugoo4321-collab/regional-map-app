# 東京23区 人口・高齢化ダッシュボード

東京都が公開する区市町村統計と行政境界データを組み合わせ、東京23区の人口構造を地図とグラフで比較するStreamlitアプリです。

## 主な機能

- 高齢化率・人口・人口密度のコロプレス地図
- 23区全体と選択した区の主要指標表示
- 指標別ランキング
- 人口密度と高齢化率の散布図
- 表示データのCSV保存
- 元データの検証と自動整形

## 使用データ

- 統計：東京都「区市町村統計表（2026年）」
- 行政境界：国土交通省「国土数値情報（行政区域データ）」をもとにNIIが加工した2023年1月1日時点のGeoJSON

人口密度は人口を面積で割って算出しています。根拠のない独自総合スコアは使用していません。

## 起動方法

    python -m pip install -r requirements.txt
    python prepare_data.py
    python -m streamlit run app.py

## ファイル構成

- `app.py`：ダッシュボード本体
- `prepare_data.py`：東京都の公開CSVから23区データを整形
- `data/tokyo_wards.csv`：アプリで使用する整形済み統計
- `data/tokyo_wards.geojson`：23区の行政境界
- `data/raw/`：取得した元データ

## 今後の拡張

人口と高齢化率の比較を土台に、医療・買い物・交通などの生活アクセスに関する公開データを追加し、地域課題をより具体的に把握できる形へ拡張します。
