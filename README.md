# 東京23区 都市構造ダッシュボード

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://teeqy5f9waeoacgwccu4yc.streamlit.app)

東京都の公開統計と行政境界データを組み合わせ、東京23区の人口・高齢化率・人口密度を、**地図で俯瞰し、2区比較で違いを捉え、散布図で都市構造を読み解く**Streamlitダッシュボードです。

## 公開アプリ

https://teeqy5f9waeoacgwccu4yc.streamlit.app

## この作品でできること

- 高齢化率・人口・人口密度を切り替えられるコロプレス地図
- 選択した区の順位、23区中央値との差、都市タイプの確認
- 任意の2区について、絶対値と「23区中央値＝100」の指数で比較
- 人口密度 × 高齢化率の散布図による4タイプ分析
- 指標別ランキング、上位・下位5区の確認
- 指標別順位と中央値差を含む統計一覧のCSV保存
- 東京都の公開CSVから23区データを検証・整形する再現可能な処理

## 設計上の工夫

### 1. 単なる可視化で終わらせない

地図、2区比較、散布図、ランキングを一つの分析導線にまとめ、利用者が「全体把握 → 比較 → 構造の発見」まで進める構成にしています。

### 2. 異なる単位を不透明に合算しない

人口・高齢化率・人口密度を一つの独自総合スコアにまとめず、公表値をそのまま表示しています。2区比較では、単位の異なる指標を比較しやすくするため、各指標の23区中央値を100とした透明な指数を補助的に使用しています。

### 3. 解釈の限界を明示する

人口密度と高齢化率の相関係数を表示しつつ、相関が因果関係を示さないことや、住宅構成・人口移動・土地利用などの背景要因を別途検討する必要があることを明記しています。

### 4. 再現可能なデータ処理

`prepare_data.py`で元CSVの列構造、自治体コード、件数を確認し、23区の整形済みデータを生成します。画面表示用のデータを手作業で書き換えない構成です。

## 使用データ

- 統計：東京都「区市町村統計表（2026年）」
- 行政境界：国土交通省「国土数値情報（行政区域データ）」をもとにNIIが加工した2023年1月1日時点のGeoJSON
- 人口密度：人口 ÷ 面積（km²）で算出

統計値と行政境界の基準時点が異なるため、境界データは地理的な比較にのみ使用しています。

## 起動方法

```bash
python -m pip install -r requirements.txt
python prepare_data.py
python -m streamlit run app.py
```

## ファイル構成

```text
regional-map-app/
├── app.py                       # ダッシュボード本体
├── prepare_data.py              # 公開CSVの検証・整形
├── requirements.txt
├── .streamlit/
│   └── config.toml              # テーマ設定
└── data/
    ├── raw/                     # 取得した元データ
    ├── tokyo_wards.csv          # 整形済み統計
    └── tokyo_wards.geojson      # 23区の行政境界
```
