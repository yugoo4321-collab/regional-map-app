# 東京23区 人口・高齢化率ダッシュボード

東京都が公開している区市町村別統計をもとに、東京23区の人口と65歳以上人口割合を比較するStreamlitアプリです。

## 主な機能

- 東京23区の人口合計と高齢化率の表示
- 区別の人口・高齢化率のグラフ
- 人口、高齢化率、自治体名による並び替え
- 東京都の公開CSVから23区のデータを抽出

## 使用データ

東京都「区市町村統計表（2026年）」を使用しています。

## 起動方法

    python -m pip install -r requirements.txt
    python -m streamlit run app.py
